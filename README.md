# Личная цифровая визитка Максима Сафрутина

Быстрая статическая визитка без сервера и сборки. Основной сценарий рассчитан на iPhone и Android: звонок, Telegram, MAX, сохранение vCard, системная отправка, SMS без ссылки и построение маршрута.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
4. После публикации откройте `https://maxsafrutin.github.io/vizitka-/`.

Сайт не использует сервер, сторонние библиотеки, трекеры или внешние шрифты. Все изображения и фирменные материалы находятся локально. `DESIGN_SYSTEM.json` — исходная спецификация V5.

## Важно

Это личная визитка, а не официальный сайт HAVAL. Фирменный знак MS используется из утверждённого brand-logo pack без изменения геометрии.
