# Личная цифровая визитка Максима Сафрутина

Персональная, адаптивная HTML-визитка с текущей деятельностью в продажах HAVAL. Неофициальный сайт.

## Публикация

1. Загрузить **содержимое** папки в корень репозитория `MaxSafrutin/vizitka-` (не саму вложенную папку).
2. В GitHub Settings → Pages выбрать `Deploy from a branch`, ветку `main`, папку `/ (root)` и нажать Save.
3. Открыть `https://maxsafrutin.github.io/vizitka-/` и проверить предпросмотр ссылки в Telegram и MAX.

В `assets/icons/` хранятся локальные иконки; `assets/portrait.jpg` - фото из вложения; `assets/share-preview.jpg` - отдельная картинка предпросмотра.

## Важно

Номер, Telegram, MAX и email взяты из ранее опубликованных личных визиток в SGM/TITAN-AUTO. Рабочие номера и почта прежних работодателей не переносились. Актуальность личных контактов стоит проверить до отправки клиентам. Название и юридический статус нового дилерского центра HAVAL не подтверждены, поэтому не указываются.
